# Oriole — for Hacker News

A native Hacker News reader for Mac, built with SwiftUI and designed to feel
first-party.

**[⬇ Download the latest release](https://github.com/warshanks/oriole-releases/releases/latest)**

Open the DMG and drag **Oriole** into **Applications**. Oriole keeps itself up
to date with [Sparkle](https://sparkle-project.org) — you can also check
manually from **Oriole → Check for Updates…**

Requires macOS 27.0 or later.

---

This repo hosts Oriole's downloads and update feed: release DMGs are attached
to [GitHub Releases](https://github.com/warshanks/oriole-releases/releases),
and `appcast.xml` is the Sparkle feed installed apps poll for updates.
